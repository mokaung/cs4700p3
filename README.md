Our overall approach to this project was to segregate the functionality of the router into different domains, then split those up and tackle them independently. Together, we first outlined the skeleton of the program by agreeing on an aggregate table as a list of dicts and wrote down skeleton functions for each function we intended to implement (in case we had to put in placeholder calls in our code). After agreeing on the basic data structure for the aggregate table and writing down core shared functionality, we then split off and had one person handle all the IP related functions, while the other worked on the data management and control layer. Once we had finished the code we merged everything together and connected the wires for all the individual functions. We generally followed the expected functionality path provided by the instructions and implemented our router that way, which each person following the evolution of features according to their designated role. The most challenging part was figuring out the overall plan and understanding the needed functionality of the router, once we had that we were able to split up and divide and conquer. We tested our code using the configs and simulation provided, and went step by step to ensure that the basic functionality was covered before moving onto the more complex functions. Overall, the project was initially overwhelming but by breaking it down, dividing and conquering, and testing pieces before moving onto more complex functionality we were able to cover and complete everything.
